# 3GPP 표준 검증 노트

AI+X HW5 웹 앱 초안. 사용자가 직접 확인한 검증 결과를 기록하는 도구입니다.
PDF 자동 분석, AI 자동 판정, 로그인, 외부 DB, 유료 API 연결은 없습니다.

## 가장 간단한 실행
압축을 풀고 루트의 `index.html`을 Chrome 또는 Edge로 여세요.
이 파일은 HTML·CSS·JavaScript를 모두 포함하므로 설치가 필요 없습니다.
단, file:// 환경의 저장 동작은 브라우저마다 다를 수 있습니다. 안정적인 사용에는 아래 HTTP 실행을 권장합니다.

## 로컬 서버 실행
Python이 설치되어 있다면 이 폴더에서 실행하세요.

```bash
python -m http.server 8000 --directory dist
```

Windows에서는 `py -m http.server 8000 --directory dist`도 사용할 수 있습니다.
브라우저에서 http://localhost:8000 에 접속하세요.
같은 브라우저와 같은 주소를 사용해야 이전 기록이 나타납니다.

## Vercel 배포
배포 준비 구성: 정적 HTML/JS, 빌드 단계 없음, 출력 폴더 `dist`, 루트의 `vercel.json` 포함.
이 실행 환경에는 Vercel 계정 연결과 CLI 인증이 없어 실제 배포 및 배포 주소 확인은 하지 못했습니다.

방법 1: 이 폴더를 Git 저장소에 올린 뒤 Vercel에서 Import합니다. Framework Preset은 Other, Build Command는 비움, Output Directory는 dist로 지정합니다.
방법 2: Node.js가 있는 본인 PC에서 이 폴더를 열고 다음 명령을 실행합니다.

```bash
npx vercel login
npx vercel --prod
```

표시되는 프로젝트 설정에서 프레임워크는 Other, 출력 폴더는 dist로 확인하세요.
계정 가입·플랜·배포 권한은 사용자의 Vercel 설정에 따릅니다.
배포 후 주소에서 추가 → 수정 → 검색 → 새로고침 → 삭제를 다시 확인하세요.

## 기능
- 주장, 표준 문서명·버전, 판정, 절·표, PDF·인쇄 페이지, 판정 이유 입력
- 추가·조회·수정·삭제(확인창 포함), 검색, 판정 필터, 전체 통계
- localStorage 저장, 새로고침 후 유지
- 필수 입력 및 PDF 페이지 정수 검사
- 저장 실패 시 입력 유지 및 오류 안내, 손상된 저장 데이터 덮어쓰기 방지
- 다른 탭에서 변경 시 새로고침 안내로 충돌 방지
- 선택적으로 추가하는 가상 시연 기록 3개. 실제 검증 결과가 아니며 페이지 근거를 생성하지 않음

## 데이터 범위
현재 기기·브라우저·접속 주소에만 저장됩니다. 동기화나 서버 백업은 없습니다.
브라우저 데이터 삭제, 사생활 보호 모드 종료, 주소 변경 시 기존 기록을 사용할 수 없을 수 있습니다.
실제 기록을 기본 제공하지 않습니다. UI 시험용 데이터도 배포 파일에 포함되지 않습니다.
수정한 시연 기록에도 '시연용 예시' 표시를 유지합니다.

## 캡처 추천
1. '시연용 예시 추가' 후 입력 폼·통계·판정별 목록이 함께 보이는 전체 화면
2. 사용자가 직접 작성한 기록의 수정 화면과 근거 입력란
3. 검색·판정 필터 결과 또는 필수 입력 누락 안내
